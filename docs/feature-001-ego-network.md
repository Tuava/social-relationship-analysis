# 功能 001：目标 QQ 号一阶扩散关系图

## 目标

给定一个目标 QQ 号，在明确授权和时间范围内，汇总所有已接入数据源中与其有关的用户、群、动态、消息、互动和资料版本，并对新发现的原子扩散一层，生成带证据链的个体中心关系图。

## 输入

```json
{
  "target_qq": "目标QQ号",
  "sources": ["qzone", "napcat"],
  "window": {
    "start": "2025-01-01T00:00:00+08:00",
    "end": "2026-08-13T23:59:59+08:00"
  },
  "depth": 1,
  "limits": {
    "max_people": 5000,
    "max_groups": 500,
    "max_messages": 100000
  }
}
```

## 处理流程

```text
校验目标账号和授权范围
→ 加载或采集目标账号直接相关数据
→ 保存全部原始记录
→ 标准化用户、群、内容和消息
→ 生成目标账号的直接关系边
→ 对新增原子扩散一层
→ 去重并建立证据索引
→ 生成图谱、摘要和待审核推断
```

## 结果分层

### 事实层

只展示接口或原始记录直接支持的事实：

- 某账号在某群消息中发言；
- 某账号评论了某条动态；
- 某账号给某条动态点赞；
- 某个时间点出现过某昵称或头像；
- 某个群在采集时对当前账号可见。

### 关系层

基于事实事件计算关系方向、次数、持续时间和时间衰减，但每个结果必须能回溯到事实层。

### 推断层

学校、爱好、职业场景等属于推断，不是事实。每条推断至少包含：

- 推断属性和候选值；
- 支撑证据事件；
- 推断方法和版本；
- 置信度；
- 是否经过人工审核；
- 反证或不确定性说明。

第一版不应根据单条关键词直接断言。例如，出现某所学校名称只能生成“可能与该学校相关”的候选推断，不能直接写成“就读于该校”。

## 验收标准

1. 能够按 QQ 号启动一次分析任务。
2. 能够留存每个数据源的原始响应和采集元数据。
3. 能够保存头像、昵称和群名片的时间版本。
4. 能够把动态、点赞、评论、回复、群、消息和用户连接为统一图谱。
5. 每条关系边都能展示来源、时间范围和证据记录。
6. 能够区分当前可见群、历史消息发现的群和有明确加入/退出证据的群。
7. 一阶扩散有节点数、消息数和时间范围限制。
8. 学校、爱好等推断不会覆盖事实资料，并且显示置信度和证据。
9. 未授权的私密内容不会进入采集任务。
