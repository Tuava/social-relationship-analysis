## 验证设计

- 默认 Go 测试与 race/vet；需要真实数据库、账号、网络或模型的旧测试明确跳过或要求 opt-in。
- PostgreSQL 16 临时空库启动、登录、未认证访问及重启迁移幂等检查。
- 回归测试覆盖媒体目录/认证、SPA 路由、私聊身份判断和 MCP 关键查询。
- Vue 类型检查、单元测试入口和 Vite 生产构建；当前没有完整浏览器自动化验收套件。
- QZone 类型检查、单元测试、bridge 与插件构建；不使用真实 Cookie。
- 每个平台包包含后端、MCP、文字时间窗采集 CLI、前端 dist、迁移、接口能力定义及运行脚本。

## 相邻发现与限制

- 原来已归错的私聊及历史关系事件不会全库自动迁移；重采消息可以更新归属，历史关系事件与衍生分析仍需复核。
- 迁移有两个 034 前缀，但执行器使用完整文件名排序及记账，不按数字前缀识别版本；本轮没有重命名已部署迁移。
- NapCat/QQ、QZone 会话、OCR/LLM 外部服务及真实发信不在无凭据 CI 的验收范围。
- 一些大型 Vue 页面、全量图计算、应用级限流与公网部署策略仍需要后续工程化；本轮不做大规模组件重构。
- 原始代码没有指定开源许可证，首次按私有仓库分发；QZone 上游 MIT 版权与许可原文保留。

## 云端验证与发布依据

发布标签仅在后端 race/vet、空库启动/登录/重启、PostgreSQL 合成回归、前端类型检查与构建、QZone 测试及两个构建、源码检查、四平台打包和 Linux amd64 发布包启动/MCP 握手全部成功后生成。验收日志通过仓库 Actions 页查看，以最终标签对应的运行结果为准。

依赖审计：前端与 QZone 的 npm 锁定依赖扫描均为 0 条已知漏洞。Go 的 govulncheck 未发现当前代码可达漏洞；另报告 3 条存在于未被当前代码调用的依赖模块中的漏洞，不应表述为 Go 所有依赖零漏洞。

视觉分析目前支持经完整解码的 PNG/JPEG/GIF；真实模型及真实媒体联调不在 CI 的验收范围。
